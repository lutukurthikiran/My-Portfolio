Check Out Below Buttons

Community Service Project

I developed a website titled "Awareness on Alcohol and Smoking" with the goal of educating people about the harmful effects of alcohol and smoking on health and society. The site provides informative content, visual data, and awareness messages to help users make informed decisions for a healthier lifestyle. It was built using HTML and CSS and is hosted at alcl-csp.netlify.app. This project helped me improve my frontend development skills and gave me a chance to work on a meaningful social cause through technology.
